# Machine Learning Collection

A collection of **machine learning projects and experiments in Python**,  
covering topics such as **classification, regression and more**.
Each project is designed to demonstrate core ML concepts through clear, well-structured implementations.

---

## 📂 Project Structure

This repository is organized by learning task (e.g., classification, regression).  
Each folder contains algorithm-specific implementations and Jupyter notebooks with experiments and visualizations.
